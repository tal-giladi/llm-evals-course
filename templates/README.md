# Templates

Fill these in when you design an eval. Each one forces a decision you would otherwise skip.

- [Failure taxonomy sheet](failure-taxonomy.md) — module 2. What can go wrong, how often, and how bad.
- [Judge prompt template](judge-prompt.md) — module 5. One judge, one failure, decidable output.
- [Eval design review](eval-design-review.md) — capstone. One page defending every number you publish.

## How to use them

Write each one by hand the first time. A template filled in by copying the previous answer is worse than
no template, because it hides exactly the decision that needed making.

Keep the filled-in copies with your eval code. They are the part of an eval suite that explains itself
six months later when nobody remembers why the threshold is 0.62.
